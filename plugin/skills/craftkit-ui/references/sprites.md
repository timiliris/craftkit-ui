# Sprites (613)

Every sprite is a CSS variable `--mc-<name>` holding a data: PNG. Size is in texture px: pass it as
`--mc-sprite-w` / `--mc-sprite-h` to `mc-sprite`. `-strip` sprites are animation frame strips (see animations.md).
Generated from `demo/sprites.json`. Do not edit: run `node build.mjs`.
