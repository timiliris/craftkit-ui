Get started

You need Node 20.11 or later and Minecraft: Java Edition 1.21.6 or later. Clone github.com/timiliris/craftkit-ui, then run npm install and npm run mc:setup (it extracts the textures and the font from your own game). Run the commands from the CraftKit UI folder.

1. Tailwind v4 project (shadcn/ui, Vite, Next.js...)

Copies the theme into your project and adds the imports after @import "tailwindcss".

node tools/install.mjs ../my-app --tailwind --patch

Without --patch it prints the lines to add. Delete shadcn's default :root and .dark color blocks: they override the theme's tokens.

@import "tailwindcss";
@import "./craftkit-ui/minecraft.css";
@import "./craftkit-ui/animations.css";

2. Any other site (HTML, PHP, a CMS...)

Compiles one stylesheet with only the classes your pages use.

node tools/install.mjs ../my-site --css
node tools/install.mjs ../my-site --css --watch

Then link it from every page. Run it again after adding classes, or keep --watch running. Write class names in full in your code.

<link rel="stylesheet" href="craftkit-ui.css">

3. Use it

Every section below shows a component with the classes to copy. The basics:

<html lang="en">              <!-- class="dark" = Modern mode -->
<body>                        <!-- page background and font come from the theme -->
  <div class="mc-panel mx-auto flex max-w-md flex-col gap-2 p-2">
    <p class="font-medium">Options</p>
    <input class="mc-text-field outline-none focus:mc-text-field-highlighted h-10 px-1.5" placeholder="Search...">
    <button class="mc-button outline-none hover:mc-button-highlighted focus-visible:mc-button-highlighted pt-1 pb-1.5 text-xs">Done</button>
    <span class="mc-bar mc-anim-fill max-w-full" style="--mc-bar-value:.6"></span>
    <span class="mc-sprite mc-anim-bob [--mc-sprite:var(--mc-item-diamond)]" role="img" aria-label="Diamond"></span>
  </div>
</body>
  • Sizes are game pixels: 1 spacing unit = 2 GUI px (h-10 = 20 px, a button). mc-scale-3 makes a block bigger.
  • Always pair a base with its states: hover: / focus-visible: / disabled: + the -highlighted or -disabled utility.
  • Avoid border-2, ring-1 and -translate-x-1/2: they break the pixel grid.
  • Click any sprite, color or texture below to copy its classes.

4. With Claude Code

CraftKit UI is also a Claude Code plugin: its craftkit-ui skill knows the install steps and every class.

/plugin marketplace add timiliris/craftkit-ui
/plugin install craftkit-ui@craftkit-ui

Then ask "add the Minecraft theme" in any project. If you move the folder, set CRAFTKIT_HOME to its new path.

5. Work on CraftKit UI itself

Rebuild the stylesheet, run this demo, or regenerate the textures and the font from your Minecraft (1.21.6 or newer).

node build.mjs --watch
node serve.mjs
npm install
npm run mc:setup
